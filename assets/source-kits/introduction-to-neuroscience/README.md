# Introduction to Neuroscience Remotion source

Install dependencies with `npm install` in this directory. Render the registered video by its `nsNN-*` composition ID with `npx remotion render <composition-id> <output.mp4>`. Source scenes are in `src/videos/`, shared course primitives in `src/components/`, and the rendering entrypoint is `src/index.ts`. The prompt cards describe the reviewed 2026-10-14 artifacts; use the source and kit for exact sequence and timing.

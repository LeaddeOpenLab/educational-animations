# Reviewed course sources

Install the pinned direct dependencies with `npm install`, then render a composition with `npx remotion render src/index.ts COMPOSITION output.mp4`.

Compositions: la03-zero-space, la04-left-zero-space, la05-orthographic-projection, la02-line-space.

Formula SVGs and shared graphics are included. Host fonts and transitive dependencies can affect rendering. Clean-machine pixel-identical reproduction is not verified. See ../../../docs/RIGHTS.md.

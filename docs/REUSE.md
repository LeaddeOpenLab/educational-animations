# Reusing an animation

Each concept keeps its original requirement, final production record and public reuse Prompt separately. A Prompt labelled `unverified` is a historical draft, not a guarantee of matching the current video. `needs_revision` means a known conflict was found. Empty aligned-Prompt fields are deliberately left pending.

For an aligned Prompt, copy it from the course page (code-block copy on GitHub, Copy Prompt on the website), then adapt it to the named tool. The Leadde animation page is a directory of creation tools; opening it does not transfer a Prompt automatically.

Reproducing Remotion output requires the exact scene source, course kit components, formula SVGs, fonts/assets and compatible React/Remotion dependencies. A prose Prompt alone does not reproduce an exact video. Available source links appear per entry; missing materials are explicitly pending. Bundles include MP4 files, index.json, PROMPTS.md and these limits in README.md.

The original source-list textbook is a course bibliography, not proof that a particular chapter supports every animation. Use the per-entry references and report errors with stable ID, version and timestamp.
